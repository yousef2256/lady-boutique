LADY BOUTIQUE — Order Manager V3

V3 fixes state/action feedback, duplicate validation, responsive controls, consistent field heights, mobile layout, and action toasts.

Open index.html directly in a modern browser. Data is stored locally in LocalStorage.

V3.1 — Products in an order are now compact cards (thumbnail, color, qty, cost, profit) edited through one popup: "＋ إضافة منتج". Supports product color, multiple images per product (drag & drop / paste / file picker, auto-compressed and stored in LocalStorage), a catalog strip to prefill, and an "add to order" button on the products page. Fixed: product row hidden on mobile, dashboard "recent orders" error that broke saving an order.

V3.2 — Liquid-glass redesign: aurora background, translucent blurred panels, flat/fill SVG icons throughout, fully polished dark mode, and an RTL/LTR bilingual (AR/EN) interface. Fully responsive on mobile with a bottom tab bar, floating new-order button, off-canvas sidebar, and tables that become stacked cards. New "المورد / Supplier" section aggregates live orders by product to generate the supplier list (total qty per product/color, per-currency cost, EGP total) with WhatsApp send, copy, .txt download, and print/PDF output.
